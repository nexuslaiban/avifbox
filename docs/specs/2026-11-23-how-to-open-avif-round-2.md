## Change

The guide answers more of what people who search for it ask, and links onward in context.

1. **The short answer first** (new № 01): a table of each system, what opens AVIF there and what to
   install, built only from facts the guide already cites. Later sections renumber.
2. **Linux** (new section): browsers always work; `avifdec` from libavif (registered source) converts.
3. **Word, email and upload forms** (new section): why they refuse AVIF and which converter to use,
   linking AVIF to JPG and AVIF to PNG.
4. **".webp and .jfif too"**: a sentence in "When nothing works" links WebP to JPG and JFIF to JPG.
5. **FAQ**: four new entries (why a download saved as .avif; renaming to .jpg; Linux; quality loss).
   The FAQPage data is built from the same list, so it still matches the page.
6. Related cards: the viewer replaces WebP to PNG. Description names Linux. `updated` → 2026-11-23.

Out of scope: the title, which already carries the query and fits AC-22; screenshots (they would need
real captures from each system).

new date (AC-31). No new external link that is not in `src/content/sources.ts` (AC-30).
