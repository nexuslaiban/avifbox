# AVIFBox — converters that make AVIF

Date: 2026-11-23 · Source: the SEO review of the same day. Every page so far converts *from* AVIF, JFIF
or WebP. The searches "jpg to avif", "png to avif" and "webp to avif" are answered by competitors with
pages of their own; AVIFBox has none, though its name says AVIF.

## Change

1. **Engine: `avif` target.** `Target` gains `'avif'`. `src/engine/avif.ts` encodes straight-alpha sRGB
   RGBA with `@jsquash/avif/encode.js` (libavif + aom in WebAssembly; the package was already a
   dependency, for decoding). The module (3.5 MB) is loaded on the first AVIF, in the worker. Without
   cross-origin isolation the single-threaded build is used. Output is 8-bit sRGB; `convert()` reads
   the pixels in sRGB for this target. Transparency is kept unless a fill colour is chosen. Animated
   input is written one still AVIF per frame. `defaultOptions('avif')` starts at quality 60.
2. **UI.** For an AVIF target the settings show an "AVIF output" quality slider (with a note on the
   scale and the one-off encoder download) and the PNG transparency control. The colour profile choice
   is disabled with "AVIF output is written in sRGB." The keep-original JPEG choice is JPG-only.
3. **Pages.** `/jpg-to-avif`, `/png-to-avif`, `/webp-to-avif`, from the existing `ToolPage` template:
   how-to, comparison, prose, FAQ (with FAQPage data from the same list), packing list, related cards.
   Copy shared by the three is in `src/content/tools/avif-output.ts`. Each cites registered sources.
4. **Navigation.** A "To AVIF" group in the Converters menu (the menu's heading ids now replace spaces).
   Home: a card and a table row for each. `RELATED` gains the three.
5. **Tests.** `TOOLS` lists the ten converters; AC-24 gains their required links; the menu test knows
   the "To AVIF" group; the home body limit goes from 900 to 1,000 words, because each converter adds a
   card and a table row. New AC-60 and AC-61: real AVIF bytes (`ftypavif`), the right size, smaller at a
   lower quality, and names taken from the source.

Out of scope: animated AVIF output, lossless AVIF, 10/12-bit and Display P3 output, an AVIF choice on
the home converter, the home `<title>` and description (still "AVIF to PNG or JPG"), `/about` copy.

## Existing behaviour changed

- `Target` is a three-way union; every `options.target === 'png' ? … : jpg` branch was checked.
- Menu heading ids: `menu-to-avif` (no change for one-word groups).
- Sitemap: 13 → 16 URLs.
